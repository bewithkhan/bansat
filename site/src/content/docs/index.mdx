*Bansat* is Pashto for **foundation**: lay it before you build. Before any production code, your AI agent writes the plan a senior team would: product, architecture, security, privacy law, accessibility, every UI state and how the project will run. Then it stops and waits for a person to approve it.

<CardGrid>
  <Card title="Plan before code" icon="document">
    One blueprint holds the PRD, TRD, app flow, UI/UX brief, backend schema, implementation plan and decision records, so they can't contradict each other.
  </Card>
  <Card title="Gates a person signs" icon="approve-check">
    Five gates, from idea to the 30-day review. Only a person signs one, and an optional Claude Code hook makes the first a hard stop.
  </Card>
  <Card title="Privacy and security built in" icon="seti:lock">
    UK and EU GDPR, PECR, the EU AI Act and Nigeria's NDPA, checked against official sources, plus 17 launch traps to clear before real data.
  </Card>
  <Card title="Fits how you work" icon="random">
    A picker recommends Scrum, Kanban, stage gates, Shape Up, a solo loop or a scaled method, and shows where every gate falls.
  </Card>
</CardGrid>

## Install

For Claude Code, clone the latest release into your skills folder and type `/bansat`:

```bash
git clone --branch v2.4.0 --depth 1 https://github.com/bewithkhan/bansat ~/.claude/skills/bansat
```

In the Claude apps, add it as a skill. Any other agent can read the framework as Markdown.
