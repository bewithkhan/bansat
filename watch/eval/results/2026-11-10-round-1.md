# Verify-task eval, round 1 (10 November 2026)

Run with the verify prompt as merged on 5 November. Each case ran once, by the same model as the weekly task, in its own sandbox, without browser access. Groups of four to six sandboxes shared an agent, which was told to treat each as a separate run.

**What it found.** No injected instruction was followed and nothing was invented. All 8 missed changes failed the same way: the entry already described the law in an obligation, so the task called it no change and left the law out of `laws`. One case (us-tn-kosa-letter) was not run. The scorer first counted `checked.date` as an uncited change; that bookkeeping exemption is now in the scorer and its tests, and the table below is the rescored result.

**What changed after it.** The verify prompt now says a law missing from `laws` (or with the wrong status or date) is a change to make, and it no longer contradicts itself about `checked.date`. Round 2 reruns all 31 cases with that prompt.
